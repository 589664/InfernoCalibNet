## **What `Pr()` Does**

- 🧠 Computes $P(Y \mid X, \text{data})$ using a model trained with `learn()`.
- 🔄 Uses Monte Carlo sampling to simulate many versions of $P(Y \mid X)$ across plausible worlds.
- 📦 Returns:
  - `values`: mean prediction (model’s best guess)
  - `samples`: individual predictions (reflecting uncertainty)
  - `quantiles`: credibility intervals (e.g., 89%) summarizing prediction spread

## **📊 Interpreting Quantiles**

Quantiles describe **uncertainty in predicted probabilities**.

📌 Example: `quantiles = c(0.055, 0.25, 0.75, 0.945)`

| Percentile | Meaning |
|------------|---------|
| 5.5%       | Lower bound (89% interval) |
| 25%        | Lower bound (50% interval) |
| 75%        | Upper bound (50% interval) |
| 94.5%      | Upper bound (89% interval) |

✅ These give:
- **50% interval** → between 25% and 75%
- **89% interval** → between 5.5% and 94.5%

🧠 Quantiles reflect the model’s belief uncertainty, **not** direct uncertainty about the true outcome.

## **Probability of a Probability?**

- Bayesian models treat probabilities as random variables.
- Each sampled model offers slightly different $P(Y \mid X)$.
- The result: a **distribution of predictions**, expressing **epistemic uncertainty** (knowledge uncertainty).

## **⚙️ Practical Usage**

- 🛠️ Choose quantile ranges depending on the need:
  - `c(0.025, 0.975)` → 95% coverage
  - `c(0.25, 0.75)` → 50% tighter interval
- 📚 Inferno defaults to 89%, balancing robustness and informativeness (~1 Shannon bit of uncertainty).

## **🖼️ Visualization**

- `plot(probs)` → shows mean prediction with shaded uncertainty regions.
- `plotFsamples()` → visualizes how the model believes variables are distributed.
- `samples` → allow deeper exploration of model variability.

## **📘 Posterior Distribution**

| Component    | Meaning                  |
|--------------|---------------------------|
| **Prior**    | Belief before data         |
| **Likelihood** | How probable data is under model |
| **Posterior** | Updated belief after seeing data |

🧮 Bayes' theorem:
$P(\theta \mid \text{data}) = \dfrac{P(\text{data} \mid \theta) \times P(\theta)}{P(\text{data})}$

Posterior distributions form the foundation of predictions, uncertainties, and informed decisions.

## **✅ Summary**

- `Pr()` provides distributions, not just point estimates.
- Quantiles capture how sure the model is about predictions.
- Bayesian inference helps integrate uncertainty naturally.

## **🔍 Inferno Output Diagnostics**

| Component | Description |
|-----------|-------------|
| 🔁 Chains | Independent explorations of model space |
| 🎲 Samples | Posterior samples to compute predictions and uncertainty |
| 🌌 Dimensionality | Effective dimensions of sampled parameter space |
| ⏱️ Max MC Iterations | Steps needed for convergence |
| 🧪 Mixture Components | Complexity needed to represent posterior |
| 📉 MC Standard Error | Measures estimate stability |
| 📦 Effective Sample Size | Quality of independent information |
| 🧹 Thinning | Corrects for chain autocorrelation |

## **🔧 How `vrtgrid()` Works**

- **Purpose**: Generate grids for input variables based on metadata.
- **Usage**:
  ```r
  logit_range <- vrtgrid("LOGIT_EFFUSION", learnt = inferno_model, length.out = 100)
  ```
- Produces meaningful, properly ranged values for variable analysis.

## **📊 How `plotFsamples()` Works**

- **Purpose**: Visualize learned distributions for each variate.
- **Options**:
  - Add data histograms with `datahistogram = TRUE`
  - Add scatterplots with `datascatter = TRUE`
- **Input**: Output file name, model, optional real data.

Helps understand what the model *thinks* each variable looks like across the population.

## **🤔 Understanding Bayesian Uncertainty**

Bayesian models update predictions based on evidence.

| Scenario | Interpretation |
|----------|-----------------|
| 🔵 Frequent events | Tight prediction (low uncertainty) |
| 🔴 Rare but well-measured | Confident unlikely |
| ⚠️ Rare and poorly measured | High uncertainty |

More observations → higher confidence
Less data → greater caution ⚠️

## **📈 How This Appears in Plots**

- Narrow shaded regions = confident prediction
- Wide bands = greater predictive uncertainty

Seen in `plot(probs)` and `plotFsamples()` outputs.

## **🧠 Takeaway**

Bayesian models offer **probabilities + uncertainties**, not just guesses.
They **express belief strength**, guiding safer decisions under uncertainty.
